# 手机端页面与操作层级

Bridge 手机端按“日常工作、电脑管理、App 偏好”组织为三个一级入口：**会话、电脑、设置**。

## 会话

已配对用户启动后进入最近电脑的会话目录；首次使用进入配对引导。目录只读取项目和会话清单，主动选择会话后才加载历史。

```text
会话目录
├─ 当前电脑 → 电脑列表
├─ 搜索项目或会话
├─ 新建 → 选择桌面应用、项目、可选标题
├─ 桌面应用筛选（多应用时显示）
├─ 待处理 → 对应会话的审批或提问
├─ 项目
│  ├─ 主会话
│  │  └─ Fork 分支 → 更深分支
│  └─ 查看全部 → 项目完整列表
└─ 已归档会话 → 搜索、查看、恢复、删除
```

项目保持原位展开。Fork 按直接父子关系逐级展开和收起；返回目录保留搜索、展开状态和滚动位置。

目录“更多”提供同步与项目展开收起。会话行“更多”与对话页共用操作菜单。

## 单个会话

打开会话后隐藏一级底栏，留出消息和输入空间。

| 位置 | 内容 |
| --- | --- |
| 顶栏 | 返回、标题和状态、会话操作 |
| 内容切换 | 对话 / 成果 |
| 对话内容 | 消息、工具、子代理报告、审批、提问、分支与接力链接 |
| 成果 | 文件变化、每轮成果、预览与下载 |
| 输入区上方 | 当前模型和会话设置、运行中任务的停止操作 |
| 输入区 | 图片附件、文本、发送；运行中按能力显示排队或立即调整 |

会话操作菜单按用途分组，并只显示主机和桌面应用支持的功能：

- **会话设置**：模型、思考强度、快速模式、上下文用量、本会话授权。
- **分支与接力**：创建 Fork、切换执行来源、交给其他桌面应用。接力沿用原有预览和确认步骤。
- **管理**：同步、归档或恢复。
- **危险操作**：删除；需要确认，运行中或接力中的会话禁止删除。

会话设置里的授权只影响当前会话，可选择跟随电脑、标准授权或完全授权。完全授权保留确认；不会因为打开设置而改变权限。

## 电脑

电脑列表标记当前电脑。点击当前电脑查看详情；其他电脑明确提示“切换到此电脑”。普通切换进入目录，“查看待处理”才定向打开某个会话。

电脑详情包含：

1. **连接与同步**：电脑在线状态、连接状态与方式、延迟、待发送数、电脑端版本、重新连接、同步、连接诊断。
2. **桌面应用控制**：应用状态、启动与退出；退出需要确认。
3. **电脑默认授权**：按桌面应用分别设置。Claude 默认授权可独立设置；其他应用通过已有会话读取配置，没有有效会话时说明限制。
4. **移除电脑**：清除该电脑在手机上的配对和缓存，并按已有机制撤销访问；需要确认。离线的非当前电脑也可以从列表移除。

切换一级页签与查看当前电脑详情不会断开连接。主动切换电脑、重连和移除继续使用原有连接流程。

## 设置

- **外观**：浅色、深色。
- **风格**：Sunstone、Apple；保留已有偏好。
- **诊断与支持**：记录、查看、复制或导出诊断日志，连接探测和高级排错。

电脑详情和设置共用已有诊断工具。清理缓存并重连位于高级排错区，说明影响手机上全部已保存电脑的缓存，并需要手动确认。

## 返回规则

Android 系统返回与页面返回按当前层级工作：

- 先关闭当前确认或弹层，再返回下层页面。
- 成果先返回对话；对话再返回原目录或项目列表。
- 项目或归档列表返回会话目录。
- 电脑详情返回电脑列表；电脑、设置一级页返回会话页。
- 返回和切页不停止电脑上的任务。

首次配对、扫码与同步保持独立流程；同步完成前不切换页面。桌面端继续使用原有导航和完整配置入口。
