# 手机端设计规范与页面层级（两层扁平首页目录 + 推入二级页架构）

Bridge 手机端与桌面端共用同一套 **扁平项目与会话目录树（`MobileSessionCatalog` / `DesktopSessionsPane`）、受控对话视图（`ConversationView`）、全画布新建会话（`NewChatCanvas`）、去重成果列表及无框发丝线设置体系**。手机端采用清晰的 **两层页面结构**：已配对设备启动后进入全屏 **一级首页会话列表（`MobileSessionCatalog`）**（首次使用或未配对进入扫码配对页）；点击会话、新建会话、助理、电脑或设置后推入对应 **二级全屏视图**，顶栏左侧统一显示 `←` 返回按钮并支持 Android 系统返回键逐级回退。样式变量定义在 `apps/client/src/mobile.css`，颜色统一读取 `styles.css` 的主题变量，同时兼容 Sunstone 与 Apple 的浅色与深色模式及双轴动态字号回流（`data-effective-scale`）。

## 设计规范

### 尺寸与栅格

| 用途 | 变量 / 尺寸 | 值 |
| --- | --- | --- |
| 页面左右安全边距 | `--m-gutter` | 16px（`更大` 字号或系统放大到 `xlarge` 时 12px；顶栏、首页列表与底栏都取它与 `env(safe-area-inset-*)` 的较大值） |
| 页面大标题 | `--m-fs-large-title` | `calc(22px * var(--font-scale))` |
| 顶栏标题、面板与对话框标题 | `--m-fs-title` | `calc(16.5px * var(--font-scale))` |
| 正文、操作名称 | `--m-fs-body` | `calc(15.5px * var(--font-scale))` |
| 次要正文、胶囊与链接操作 | `--m-fs-callout` | `calc(14.5px * var(--font-scale))` |
| 分组与微标题 | `--m-fs-subhead` | `calc(13.5px * var(--font-scale))` |
| 说明、状态、章节小标 | `--m-fs-footnote` | `calc(13px * var(--font-scale))` |
| 状态标签与徽标 | `--m-fs-caption` | `calc(12px * var(--font-scale))` |
| 最小触控区域 | `--m-touch` | 44px |
| 发丝线列表与设置行高 | `--m-row` | 54px |
| 按钮、输入框与胶囊圆角 | `--m-r-control` | 10px（手机端 `--r-btn` 统一取此值） |
| 操作组与弹出菜单圆角 | `--m-r-group` | 14px |
| 底部操作面板圆角 | `--m-r-sheet` | 20px |
| 底部面板与弹出菜单底色 | `--m-sheet-fill` / `--m-popover-fill` | 浅色取主题背景／表面色，深色按 Sunstone、Apple 各取一档 |

搜索框、配对输入框与路径输入框字号保持不小于 `16px`，避免移动浏览器聚焦时自动放大视口。结合应用内 4 档字号（`小 / 标准 / 大 / 更大`）与系统无障碍 `textZoom` 计算 `data-effective-scale`（`large` / `xlarge`），在大字号窄屏（如 `360px`）下自动将设置行与按钮组回流为纵向无溢出布局。

### 卡片边界、弹层与状态点

- **上层界面去卡片化**：首页项目与会话树、设置页、已配对电脑页、电脑详情页、助理设置、助理邮件列表与新建会话配置一律采用 **微标题 + `1px` 发丝线分隔行**，外层不套圆角白底卡片框。首页的权限提醒、连接问题与 Claude Desktop 启动提示共用同一种暖色提示条。
- **仅对话流与弹层保留结构化卡片**：代码块、工具调用组、`TaskPlanCard`、原生审批与提问卡片、底部 `Sheet` 操作组保留清晰卡片层级；审批与提问卡片使用与底部面板相同的手机字号档位，选项与按钮不低于 `--m-touch`。
- **统一控件样式**：首页电脑与助理胶囊、搜索框、助理设置的轮询间隔选择共用无描边的浅填充控件；状态徽标（诊断、子代理、提问标记、Fork）共用胶囊形状与 `--m-fs-caption`；错误与危险文字使用 `--danger-ink`。
- **弹层约定**：
  - 底部面板 `Sheet`：用于会话／分组对象操作、目录选择、子代理与后台任务详情等；视口宽度 `≥ 640px` 时自动居中展示，叠加二级对话框时通过 `focusPaused` 暂停底层焦点捕获。会话设置与回退对话框在 `< 640px` 时同样以底部面板呈现。
  - 确认框 `ConfirmationDialog`：仅用于删除会话、删除分组（含空分组）、移除电脑、移除邮箱、清理手机缓存、退出桌面应用等破坏性操作的二次确认。
  - 自定义菜单 `SelectMenu` 与弹出菜单：仅用于分组／模型／权限模式选择、主题快切、上下文窗口详情、`/` 命令与输入区 `+` 附件菜单；它们共用 `--m-popover-fill` 底色、`--line-strong` 描边与 `--m-r-group` 圆角。
  - 思考强度用分段按钮：首项 `默认` 交给 Claude Desktop 决定，其后只列出当前模型可选的档位；模型不支持思考强度时整行隐藏。
- **操作行约定（`SheetAction` / `.m-group`）**：
  - 底部面板操作按用途分组（`.m-group`），组内行间用细线分隔；破坏性操作放在最后一组，名称和图标标红。
  - 当前不可用的操作保留在原位并说明原因；处理中禁用全部操作并在面板底部显示处理状态或失败原因。
- **状态点颜色**：在线为主色实心；运行中为主色加外环；排队／等待处理／需重配为暖色；失败为危险色；空闲、离线与未连接为浅灰实心。会话行、对话页顶栏、首页电脑快切胶囊、侧栏与电脑列表共用同一套状态点，不另用成功绿。

### 一级首页会话列表（`MobileSessionCatalog` / `.mobile-home-catalog`）

已配对设备启动后进入最近活跃电脑的首页会话列表；目录仅读取项目与会话清单，主动点选会话后才按需加载历史：

1. **顶栏（`.mobile-drawer-topbar`）**：
   - 左侧 `● <电脑名> ▾` 电脑快切胶囊（`drawer-host-switcher`）：电脑名超长时优先截断名称并始终保留状态点，点击原位展开 `快捷切换电脑` 列表与 `+ 扫码添加新电脑`。
   - 中部内联 `✉ 助理` 胶囊（`drawer-assistant-capsule`，宿主声明 `plugin.assistant-mail.v1` 时显示）：展示未读圆点与未读数徽标（上限 `99+`），点击推入助理页。
   - 右侧 `[新建会话]` 图标按钮（`SquarePen`）：点击推入全画布 `NewChatCanvas`。
2. **无框柔和搜索框**：`搜索项目或会话`，实时过滤活跃分组与已归档家族。
3. **扁平项目分组与三层嵌套会话家族树**：
   - `项目` 微栏：右侧提供 `+ 分组`（支持 `section.create.v1` 时打开 `SectionCreateDialog`）与 `排序`（多分组时打开 `ProjectOrderSheet`）。
   - 分组头加粗展示并带发丝线分隔；当电脑存在自定义分组时，未归入任何分组的会话统一归入 `未分组`（支持作为拖放目标将已分组会话移回未分组）。`0` 会话手动分组默认折叠，新建后自动展开；分组头右侧提供 `+`（在该分组新建会话）与 `⋯`（重命名或删除分组）。
   - 会话按 **主会话 → Fork 分支 / `/btw` 侧聊（区分 `GitFork` 与 `MessageCircle` 图标）→ 更深子分支** 组成最多三层嵌套树，支持逐级展开／收起及长按跨分组拖放（含上下边缘自动滚动）。会话行右侧 `⋯` 打开共享 `SessionActionSheets`。
   - 列表底部展示默认折叠的 `▸ 已归档 (N)` 分组，点击原位展开已归档会话家族进行查看、恢复或删除；返回首页时保留搜索词、展开态与滚动位置。
4. **底部固定栏（`.mobile-drawer-dock`）**：左侧提供 **`电脑` · `设置`** 入口，右侧提供 `ThemeMenu` 主题与深浅色快切按钮。

### 二级推入视图与顶栏（`MobilePageHeader`）

所有二级页顶栏左侧均为 `←` 返回按钮：

- **对话视图（`ConversationView`）**：
  - 顶栏：左侧 `←`（返回会话列表）｜中部单行会话标题 + **配置摘要**（首行模型，次行 `思考强度 · 权限模式`，例如 `Opus 4.7` / `高 · 逐个确认`，过长时截断，末尾 `▾`，点击打开会话配置）｜右侧 `[成果 N]` 视图切换胶囊 + `⋯`（打开与首页会话行一致的 `SessionActionSheets`，`成果` 图标与顶栏胶囊相同）。
  - 子分支／侧聊顶部仅展示指向父会话的 `ForkChainBar` 返回链条；主会话不重复渲染子分支横条。
  - 原生审批与多选提问以内联卡片展示在对话流中；当 Claude Desktop 未运行或 `调试端口 9229` 未开启时，支持一键远程启动 Claude Desktop 并开启调试端口。
- **新建会话画布（`NewChatCanvas`）**：
  - 顶栏：左侧 `←`｜中部静态标题 **`新建会话`**。从首页进入时 `←` 为 `返回会话列表`；从会话 `⋯` 进入时为 `返回会话`，回到原会话。
  - 画布内联提供工作目录选择（支持浏览电脑目录与单层新建文件夹）、所属分组选择（含 `+ 新建分组…` 内联创建）、可选自定义会话标题（留空则在首轮消息发送后自动总结生成短标题，手动填写则永久保留）、模型（占位 `默认`）、思考强度、权限模式与输出风格（`默认` 沿用 Claude Desktop 的设置）选择，并直接共用底部输入框发送首轮指令。
- **助理页（`AssistantPage`）**：左侧 `←`（返回会话列表）｜中部 `助理`｜下方 `对话 | 收件 | 议程` 切换器（按宿主能力显示）、`刷新邮件列表` 与 `助理设置`。`助理设置` 按 `←` 或系统返回回到打开它之前的视图。会话绑定、更换会话与初始化托管助理只在 `助理设置` 里；未绑定时打开助理默认进入 `收件`，`对话` 页签显示 `尚未绑定会话` 与 `前往助理设置`。支持将邮件引用显式发送到绑定的原生会话；自动投递保持关闭。
- **已配对电脑与电脑详情（`HostBrowser` → `MobileHostDetails`）**：
  - `已配对电脑`：左侧 `←`（返回会话列表）｜中部 `已配对电脑`｜右侧 `+ 扫码`。点击电脑行切换到该电脑会话列表；电脑行 `⋯` 提供 `连接与电脑设置` 与需确认的 `移除这台电脑`（与电脑详情页底部共用同一确认流程）。
  - `连接与电脑设置`（`MobileHostDetails`）：左侧 `←` 返回 `已配对电脑`；从首页 `检查连接` 打开时为 `返回会话列表`，从 `设置` 打开时为 `返回设置`，各自回到来处。包含连接状态／传输路径／延迟／待发数／中继地址保存、Claude Desktop 启停（退出需确认）与远程开启调试端口（显示电脑端的开启结果）、`调试端口 9229` 状态、仅检查模式的 `版本与更新`（`电脑端版本`、更新状态、`稳定版 | 预发布` 通道与单一 `检查更新`，不提供远程下载或重启升级），以及 `移除这台电脑`。
- **设置页及子页（`MobileSettings` → `模型与网关` / `Magpie 额度`）**：
  - `设置`：左侧 `←`（返回会话列表），按发丝线分组依次展示 `当前电脑 · <电脑名>`（`连接与电脑设置`、`模型与网关`、`Magpie 额度`（声明 `plugin.magpie-quota.v1` 时显示，进入子页自动刷新并在失败时回退缓存）三个入口；调试端口与电脑端版本都在 `连接与电脑设置` 里）、`外观`（Sunstone / Apple、浅色 / 深色、4 档字号）、`通知`（`任务通知` 开关与系统通知授权）、`版本与更新`（本机 `当前版本`、更新通道，检查 GitHub Releases 并一键跳转系统浏览器发布页下载）及 `诊断与支持`（按需拉取的有界诊断日志查看、复制、导出与需确认的缓存清理重连）。
  - `模型与网关`、`Magpie 额度` 为设置页推入子页，左侧 `←` 返回 `设置`。

### 浮动输入框、草稿持久化与会话命令菜单（`MobileComposer`）

- **浮动输入框与上下文窗口详情**：
  - 左下角 `+` 附件菜单按钮 + 运行／排队精简状态；右下角可点击上下文占用胶囊（如 `29%`，未知窗口容量的自定义模型省略上限与百分比）+ 发送／停止按钮（运行中会话停止操作保留影响说明与确认；后台子代理可在其详情卡片上单独停止，长时间无进展时提示可能卡住）。
  - 点击上下文百分比弹出 `上下文窗口` 详情浮层（Token 拆分进度条及支持 `session.command.v1` 时的 `/compact` 压缩快捷按钮）。
  - 未发送文本草稿按 `(hostId, sessionId)` 隔离并持久化到 `localStorage`，跨切页、返回与刷新不丢失且不会自动重发。
- **会话命令菜单（`/`）**：
  - 在输入框开头输入 `/` 打开当前会话支持的内置命令与个人／项目 `commands`、`skills` 列表（隐藏 `user-invocable: false`，不传输命令文件正文），手机端与桌面端共用同一菜单，显示说明、参数与不可用原因。
  - 支持点击、方向键、`Enter`／`Tab` 选择；选中仅填入草稿并保留参数与后文，点击发送才执行；`Esc`、点外或系统返回关闭菜单并保留草稿；命令不携带附件。
  - `/compact`、`/model`、`/permissions`、`/clear`（`/new`）、`/fork`、`/resume`、`/rename` 均以 Claude Desktop `LocalSessions` 实际能力与会话边界为准，不会启动独立 SDK 进程或自动接管。`/permissions` 原样作为一轮消息交给 Claude Desktop（电脑端返回 `sent`；`session.permissions` 返回不支持，Bridge 不提供允许／拒绝规则编辑），手机上权限模式只在会话设置里修改。不带名称的 `/rename` 打开 `⋯` 菜单同一个重命名对话框，`/rename <名称>` 原样交给 Claude Desktop。

### Fork 语义与成果视图（按最近更新倒序）

- **Fork 分支边界**：Fork 使用当前选中父链的完整轮次边界，正在进行的输入和半轮回答不进入新分支；继承的子代理记录仅作历史展示，不授予子分支停止父会话后台任务的权限；分支共享工作目录，创建分支不回滚文件。
- **成果视图（按最近更新排序）**：
  - 点击对话顶栏 `[成果 N]` 切换到当前会话的成果列表（再次点击或按系统返回回到对话）。
  - 合并同一文件的多次写入与修改，按文件 **最近更新时间倒序（`lastUpdatedAt` DESC，`01` 为最新产出或修改的文件）** 排列，展示最新快照状态（`新增 | 修改 | 删除 | 重命名`、体积或累计增删行数），支持一键预览（超过 `1 MiB` 先读取元数据并确认体积后分块下载，离线仍可打开已缓存预览，保留 `20 MiB` 传输上限）与完整文本复制／下载。
  - 列表底部只有一个 `加载更多`：先补全当前快照的剩余文件，再加载更早的成果。

| 切换对话／成果列表 | 对话顶栏右侧 `[成果 N]` 胶囊或会话 `⋯` |

| 重命名、移动到分组、同步、PR 自动修复、Fork、归档、删除会话 | 对话顶栏 `⋯` 或首页会话行 `⋯`（共享 `SessionActionSheets`） |
| 连接重连、中继地址、Claude Desktop 启停与调试端口、电脑端版本检查、移除电脑 | `设置` → `连接与电脑设置`，或 `已配对电脑` 页电脑行 `⋯` → `连接与电脑设置` |
| Magpie 额度、外观与字号、通知、本机版本与系统浏览器下载更新、诊断日志 | 首页底部栏 → `设置` 页 |

## 返回规则

Android 系统返回与顶栏 `←` 返回按注册优先级（`registerMobileBackHandler`）工作：

1. **配对同步锁**：正在导入配对信息（`pairingSync`）时拦截返回，避免中断密钥同步。
2. **优先关闭顶层覆盖物**：先收起打开的客户端更新弹窗、二次确认框、底部 `Sheet`（如会话操作、后台任务／子代理详情、会话配置）、`SelectMenu`、文件预览器、上下文窗口浮层或 `/` 命令菜单。
3. **二级子视图逐级回退**：
   - 会话内 `成果` 视图先返回当前会话的 `对话` 视图。
   - `对话` 视图返回一级 **首页会话列表**（保留目录搜索、分组展开态与滚动位置）；`新建会话` 画布从会话 `⋯` 进入时返回原会话，否则返回首页。
   - `助理设置` 返回打开它之前的助理视图。
   - `连接与电脑设置` 返回 `已配对电脑` 列表（从首页 `检查连接` 打开时返回首页，从 `设置` 打开时返回 `设置`）；`模型与网关`、`Magpie 额度` 返回 `设置` 页；从已配对状态临时打开的扫码页返回原页面。
4. **非首页一级入口回退首页**：位于 `助理`、`已配对电脑` 或 `设置` 根视图时，按 `←` 或系统返回回到一级 **首页会话列表**。返回与切页不会发送或清空未发送草稿，也不会中断电脑端正在运行的任务。
5. **首页根列表释放返回**：位于一级首页会话列表（或首次未配对页）且无弹层打开时，系统返回交还宿主系统退回桌面；软键盘显示时先由系统收起键盘。
