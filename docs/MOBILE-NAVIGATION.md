# 手机端设计规范与页面层级（v3 统一无框抽屉架构）

Bridge 手机端与桌面端共用同一套 **扁平项目与会话目录树、对话与新建会话画布、去重产出文件列表及无框发丝线设置体系**。手机端取消独立的会话目录落地页和外层分组白卡框：已配对设备启动后 **直达当前活跃会话**（无活跃会话时直达 **新建会话画布**），左上角 `☰` 菜单滑出扁平左抽屉进行会话、项目、电脑与设置切换。样式变量定义在 `apps/client/src/mobile.css`，颜色统一读取 `styles.css` 的主题变量，同时兼容 Sunstone 与 Apple 的浅色与深色模式。

## 设计规范

### 尺寸与栅格

| 用途 | 变量 / 尺寸 | 值 |
| --- | --- | --- |
| 页面左右安全边距 | `--m-gutter` | 16px（叠加 `env(safe-area-inset-*)`） |
| 滑出左抽屉宽度 | `.mobile-drawer` | `min(82vw, 308px)` |
| 顶栏标题、面板标题 | `--m-fs-title` | 16px |
| 正文、操作名称 | `--m-fs-body` | 15px |
| 次要正文 | `--m-fs-callout` | 14px |
| 分组与微标题 | `--m-fs-subhead` | 13px |
| 说明、状态、章节小标 | `--m-fs-footnote` | 12px |
| 最小触控区域 | `--m-touch` | 44px |
| 发丝线设置行高 | `--m-row` | 52px–54px |
| 按钮与输入框圆角 | `--m-r-control` | 10px |
| 底部操作面板圆角 | `--m-r-sheet` | 20px |

搜索框与路径输入框字号保持 `16px`，避免移动浏览器聚焦时自动缩放视口。

### 卡片边界原则

- **上层界面去卡片化**：抽屉内的项目树、设置页、已配对电脑页、电脑详情页与助理设置／邮件列表一律采用 **微标题 + `1px` 发丝线分隔行**，外层不套圆角白底卡片框。
- **仅对话流与弹层保留结构化卡片**：代码块、工具调用组、`TaskPlanCard`、原生审批与提问卡片、底部 `Sheet` 操作组保留清晰卡片层级。

### 顶栏（`MobilePageHeader`）

- **对话画布顶栏**：左侧 `☰`（打开侧滑抽屉）｜中部单行会话标题 + 可点击配置摘要 `Model · Effort · PermissionMode ▾`（`Manual` / `Auto` / `Bypass` / `Accept Edits` / `Plan` / `Don't Ask`）｜右侧 `[成果 N]` 视图切换胶囊 + `⋯`（会话操作）。顶栏不重复放置新建会话按钮。
- **新建会话画布顶栏**：左侧 `☰`｜中部展示观测到的当前默认配置摘要或运行时名称。
- **设置 / 已配对电脑 / 助理顶栏**：左侧 `☰`｜中部 `16px` 页面标题｜右侧单页主动作（如已配对电脑页 `+ 扫码`、助理页刷新按钮）。
- **推入式二级页**（电脑详情、模型与网关、Magpie 额度）：左侧 `←` 返回按钮｜中部标题。

### 滑出扁平左抽屉（`MobileSessionDrawer`）

点任意一级视图左上角 `☰` 展开左抽屉，点半透明遮罩、`Esc` 或系统返回键收起：

1. **顶部电脑快切栏**：左侧 `● <电脑名> ▾` 点击内联展开已配对电脑列表与 `+ 扫码添加新电脑`；右侧仅保留 `[新建会话]` 图标按钮（点击直达新建会话画布）。
2. **置顶 `✉ 助理` 入口**（宿主声明 `plugin.assistant-mail.v1` 时显示）：位于搜索框正上方，展示未读圆点与未读数。
3. **无框柔和搜索框**：`搜索项目或会话`。
4. **扁平项目与会话树**：
   - `项目` 微栏：右侧提供 `+ 分组`（支持 `section.create.v1` 时）与 `排序`（打开 `ProjectOrderSheet` 拖拽排序）。
   - 项目分组无外框卡片；`0` 会话手动分组默认折叠（新建后自动展开），会话行单行展示标题、状态圆点、排队数徽标与 `⋯` 操作入口，不展示冗余 `[桌面运行中]` 贴纸。
   - 树底部展示默认折叠的 `▸ 已归档 (N)` 分组，点击原位展开已归档会话。
5. **底部固定栏（Dock）**：左侧仅保留 **`电脑` · `设置`** 文字入口，右侧为 `ThemeMenu` 主题快切按钮。

### 浮动输入框与上下文窗口详情（`MobileComposer`）

- 底部采用圆角浮动输入框（无通栏底条、不在输入框内重复展示模型名）：
  - 左下角：`+` 附件菜单按钮 + 运行／排队时的精简状态行（如 `● 正在回复 · 38s`）。
  - 右下角：可点击上下文占用胶囊（如 `29%`）+ 圆形发送／停止按钮。
- 点击上下文百分比弹出 **上下文窗口详情浮层**（`role="dialog"`，`aria-label="上下文窗口"`）：展示已用／上限 Token 进度条、输入提示／缓存命中／模型输出拆分，以及支持 `session.command.v1` 时的 `压缩上下文 (/compact)` 快捷按钮。

### 成果视图（去重产出文件列表）

点击对话顶栏 `[成果 N]` 切换到当前会话的产出文件列表（再次点击或按系统返回回到对话）：

- 取消按轮次折叠的证据时间轴、工具流水与置信度贴纸。
- 统一展示 **`产出文件 · 按首次出现顺序（展示最新快照）`**：按文件在会话中首次出现的先后顺序编号（`01`、`02`…），合并同一文件的多次写入与修改，仅展示最新快照状态（`新增 | 修改 | 删除 | 重命名`、体积或累计增删行数），右侧提供一键预览与分块确认下载。

## 页面与操作位置

| 操作 | 位置 |
| --- | --- |
| 打开会话树、切换助理／电脑／设置／主题 | 左上角 `☰` 滑出抽屉 |
| 快捷切换电脑或扫码添加新电脑 | 抽屉顶部 `● <电脑名> ▾` 内联面板；或抽屉底部 `电脑` 页 |
| 新建会话 | 抽屉右上角 `[新建会话]`（直达新建会话画布）或项目行 `+` |
| 新建自定义分组、调整项目顺序 | 抽屉 `项目` 微栏右侧 `+ 分组`、`排序` |
| 重命名或删除自定义分组 | 自定义分组行右侧 `⋯`（管理分组） |
| 模型、思考强度与权限模式配置 | 对话顶栏标题下方 `Model · Effort · Mode ▾` 或会话 `⋯` |
| 切换对话／成果文件列表 | 对话顶栏右侧 `[成果 N]` 胶囊或会话 `⋯` |
| 查看上下文窗口明细与执行 `/compact` | 浮动输入框右下角上下文百分比胶囊 |
| 重命名、移动到分组、同步、PR 自动修复、Fork、归档、删除会话 | 对话顶栏 `⋯` 或抽屉会话行 `⋯` |
| 连接重连、强制同步、中继地址、桌面应用启停、移除电脑 | `已配对电脑` 页对应电脑行 `⋯` → `连接与电脑设置` |
| 主题风格、深浅模式、字号、远端桌面与客户端更新、连接诊断与日志 | 抽屉底部 → `设置` 页 |

## 返回规则

Android 系统返回与页面内返回遵循以下优先级：

1. **优先关闭顶层覆盖物**：先收起打开的上下文浮层、确认框、底部 `Sheet`、文件预览器或滑出左抽屉（`drawerOpen`）。
2. **二级页逐级回退**：
   - `成果` 视图先返回当前会话的 `对话` 视图。
   - `连接与电脑设置` 返回 `已配对电脑` 列表；`模型与网关`、`Magpie 额度` 返回 `设置` 页。
   - `助理`、`已配对电脑`、`设置` 按系统返回回到当前活跃会话画布（保留会话选中态与未发送草稿）。
3. **根画布释放返回**：位于根对话画布或新建会话画布且抽屉与弹层均已关闭时，系统返回交还宿主系统退回桌面，不清空草稿、不中断电脑端正在运行的任务。
